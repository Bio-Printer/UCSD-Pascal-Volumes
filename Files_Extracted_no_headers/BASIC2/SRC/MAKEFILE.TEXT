# MAKEFILE -- B2, rebuilt: from the shell, MAKE -f BASIC2:/SRC/MAKEFILE (Tiny-C's
# MAKE, on TOOLS:).  Compiles each module whose source, or a file it #INCLUDEs, is newer than
# its object (NAME.OBJ beside it), and links each program whose modules changed, as
# BASIC2:B22.CODE ... (its map BASIC2:/MAP/B22.MAP: -MAP).  MAKE -B ... all of them again.
# MAKE -f BASIC2:/SRC/MAKEFILE INSTALL then puts them in the old ones' places (each MOVE
# deletes the old file and renames the new one; when the new one is not there it says
# so and leaves the old one).
# MAKE -B -f BASIC2:/SRC/MAKEFILE FLAGS=-K keeps every pass's file (BASIC2:/MAP/Wn), and
# MAKE -f BASIC2:/SRC/MAKEFILE DUMPALL then makes each into text (BASIC2:/MAP/Dn: B2DUMP -MAP).
